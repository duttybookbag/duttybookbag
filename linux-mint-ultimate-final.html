Bootable USB — How to Flash ISO Files
Linux Mint comes with a built-in USB flasher. You also have balenaEtcher on your desktop. Here are all the methods:
Method 1 — USB Image Writer (built into Linux Mint — EASIEST):

1. Open your Start Menu
2. Search for "USB Image Writer"
3. Click "Please select an image" → choose your ISO file
4. Select your USB drive from the dropdown
5. Click "Write" and enter your password
6. Wait for it to finish — do not unplug the USB!
Method 2 — balenaEtcher (already on your Desktop):

1. Double-click balenaEtcher on your desktop
2. Click "Flash from file" → select your ISO
3. Click "Select target" → choose your USB drive
4. Click "Flash!" and wait for it to finish
Method 3 — dd terminal method (fastest, most powerful)system
$# First find your USB drive name lsblk # Then flash the ISO (replace sdX and path to your ISO) sudo dd if=~/Downloads/yourfile.iso of=/dev/sdX bs=4M status=progress oflag=sync
⚠ WARNING: Replace sdX with your actual USB drive (e.g. sdb). The wrong drive = data loss. Always run lsblk first to confirm!
How to boot from USB:

1. Plug in your USB stick
2. Restart your computer
3. Press F12 (most computers), F8, F2, DEL or ESC right as it starts to open the boot menu
4. Select your USB drive from the list
5. The ISO will boot — you can run it live or install it

GRUB Fix — Restore Windows Boot Menu (Dual Boot)
What is GRUB? GRUB is the boot menu that appears when you start your computer and lets you choose between Linux Mint and Windows. Sometimes after installing Linux Mint, it boots straight into Mint with no menu — Windows seems to disappear. This section fixes that.
Step 1 — Try this first (works 90% of the time):

Boot into Linux Mint, open a terminal and run these two commands in order:
Install os-prober — detects other operating systems like Windowsapt
$sudo apt install os-prober -y
Enable os-prober in GRUB configsystem
$echo 'GRUB_DISABLE_OS_PROBER=false' | sudo tee -a /etc/default/grub
Update GRUB — scans for Windows and rebuilds the boot menusystem
$sudo update-grub
After running sudo update-grub you should see a line that says "Found Windows Boot Manager" or "Found Windows 10/11". If you see that — reboot and your Windows option will be back in the boot menu!
Reboot to test the boot menusystem
$sudo reboot
Step 2 — GRUB menu not showing at all? Fix the timeout:

Sometimes GRUB is set to timeout=0 so it boots instantly with no menu shown.
Open GRUB config file to edit itsystem
$sudo nano /etc/default/grub
Inside the file, find and change these two lines:

GRUB_TIMEOUT_STYLE=hidden → change to → GRUB_TIMEOUT_STYLE=menu
GRUB_TIMEOUT=0 → change to → GRUB_TIMEOUT=10

Then press Ctrl+S to save and Ctrl+X to exit nano.
Apply the changes after editing the filesystem
$sudo update-grub && sudo reboot
Step 3 — Windows still missing? Disable Fast Startup in Windows first:

Windows Fast Startup locks the drive and prevents GRUB from seeing Windows. You must disable it.

Boot into Windows (press F12 at startup and manually select Windows), then:
1. Open Control Panel → Power Options
2. Click "Choose what the power buttons do"
3. Click "Change settings that are currently unavailable"
4. Uncheck "Turn on fast startup"
5. Save changes, reboot back into Linux Mint and run sudo update-grub again
Step 4 — Fix from Windows using Command Prompt (if you can still boot Windows):

Open Windows Command Prompt as Administrator and run this command to set GRUB as the default bootloader:
Run this in Windows CMD as Administrator — sets GRUB as default boot managersystem
>bcdedit /set {bootmgr} path \EFI\ubuntu\grubx64.efi
After running the above in Windows CMD, restart the computer — GRUB menu should now appear with both Linux Mint and Windows as options.
Step 5 — Nuclear option: Boot-Repair (if nothing else works):

Boot-Repair is a tool that automatically diagnoses and fixes all GRUB problems.
Install Boot-Repairapt
$sudo add-apt-repository ppa:yannubuntu/boot-repair -y && sudo apt update && sudo apt install boot-repair -y
Launch Boot-Repairsystem
$boot-repair
In Boot-Repair, click "Recommended repair" and let it do its thing. It will automatically fix GRUB and restore the Windows entry.

Also check in your BIOS/UEFI:
• Disable Secure Boot
• Set boot order so "ubuntu" or "Linux Mint" is first (GRUB will then show the menu with Windows as an option)
• Disable Fast Boot in BIOS as well if available
Check current GRUB boot order (UEFI systems)info
$efibootmgr -v
View current GRUB configinfo
$cat /etc/default/grub
Check what GRUB detected (look for Windows lines)info
$sudo os-prober
