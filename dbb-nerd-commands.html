🔥 Bootable USB Tutorials

Before you can install Linux on any computer, you need a USB stick with the Linux installer on it. Here are all the ways to make one — from Windows, Mac, or another Linux machine.

You'll need: A USB stick at least 8GB (will be erased), an ISO file from your chosen distro's website, and one of the tools below.

🪟 Method 1 — Rufus (Windows)

The fastest, most reliable USB flasher for Windows users. Free and open-source.

Download Rufus (official site)
Windows
https://rufus.ie/en/
  1. Download Rufus from the official site (single .exe file, no installer needed)
  2. Plug in your USB stick (8GB+, will be erased)
  3. Open Rufus — select your USB drive at the top
  4. Click SELECT and choose the Linux ISO file you downloaded
  5. Leave the partition scheme as GPT (for modern computers) or MBR (for older ones)
  6. Click START — pick "Write in ISO Image mode" if asked
  7. Wait for it to finish — about 5-10 minutes
⚡ Method 2 — Balena Etcher (Works Everywhere)

Same simple tool on Windows, Mac, and Linux. If you switch computers, you don't have to learn anything new.

Download Balena Etcher
Windows Mac Linux
https://etcher.balena.io/
  1. Download Etcher for your operating system
  2. Install it (or just run the AppImage on Linux)
  3. Open Etcher → click "Flash from file" → select your ISO
  4. Click "Select target" → choose your USB drive
  5. Click "Flash!" and wait until done
📦 Method 3 — Ventoy (Multi-ISO USB)

Game-changer. Install Ventoy on a USB once — then just drag-and-drop multiple ISO files onto it. At boot, you pick which one to install. Try 5 distros without re-flashing.

Download Ventoy
Windows Linux
https://www.ventoy.net/en/download.html
  1. Download Ventoy for Windows or Linux
  2. Run Ventoy2Disk → select your USB → click Install (one-time setup)
  3. After install, the USB has a Ventoy partition — just copy ISO files directly onto it
  4. Boot from the USB and you'll get a menu of all the ISOs on it
⌨️ Method 4 — dd Command (Linux/Mac)

No software needed. Built into every Linux and Mac. Fastest method but ZERO safety nets — wrong drive letter = wiped drive.

Step 1 — Find your USB drive name
LinuxMac
lsblk
Step 2 — Flash the ISO (replace sdX with your drive)
Linux⚠ Triple Check
sudo dd if=~/Downloads/yourfile.iso of=/dev/sdX bs=4M status=progress oflag=sync

⚠ WARNING: Replace sdX with your actual USB drive (like sdb, never sda — that's usually your hard drive). Wrong drive = total data loss with no recovery. Always run lsblk first to confirm.

🐧 Method 5 — USB Image Writer (Linux Mint Built-In)

If you're already on Linux Mint, this comes pre-installed. Easiest method on Mint.

  1. Open the Start Menu
  2. Search for "USB Image Writer"
  3. Click "Please select an image" → choose your ISO
  4. Pick your USB drive from the dropdown
  5. Click "Write" and enter your password
  6. Wait for it to finish — don't unplug until the success message appears

How to boot from your new USB:

1. Plug in the USB stick

2. Restart the computer

3. Right as it starts, press F12 (most computers), or F8 / F2 / DEL / ESC to open the boot menu

4. Select your USB drive from the list

5. The Linux installer will boot — try it live first or click Install

🔧 GRUB Fix — Restore Windows Boot Menu (Dual Boot)

You installed Linux next to Windows. Everything was fine. Then a Windows update ran and now you boot straight into Windows with no Linux option — or vice versa, you boot straight into Linux and Windows seems to have vanished. Your operating systems are still there. The boot menu just got broken. Here's how to bring it back.

What is GRUB? GRUB is the menu that shows up when you start your computer and lets you choose between Linux and Windows. After installing Linux Mint or Ubuntu, sometimes this menu breaks or disappears. Every fix below targets a different cause.

Step 1 — Try This First (Works 90% of the Time)

Boot into Linux, open a terminal, and run these three commands in order:

Install os-prober — detects Windows on your drive
Debian/Ubuntu
sudo apt install os-prober -y
Fedora
sudo dnf install os-prober -y
Arch
sudo pacman -S os-prober
openSUSE
sudo zypper install os-prober
Enable os-prober in GRUB config
All Distros
echo 'GRUB_DISABLE_OS_PROBER=false' | sudo tee -a /etc/default/grub
Update GRUB — scans for Windows and rebuilds the menu
Debian/Ubuntu
sudo update-grub
Fedora
sudo grub2-mkconfig -o /boot/grub2/grub.cfg
Arch
sudo grub-mkconfig -o /boot/grub/grub.cfg
openSUSE
sudo grub2-mkconfig -o /boot/grub2/grub.cfg

After running the update, look for a line that says "Found Windows Boot Manager" or "Found Windows 10/11". If you see that, reboot and Windows will be back in the boot menu.

Step 2 — GRUB Menu Not Showing At All? Fix the Timeout

Sometimes GRUB is set to timeout=0, which makes it boot straight into the default OS with no menu shown.

Open GRUB config file to edit
All Distros
sudo nano /etc/default/grub

Inside the file, find and change these two lines:

GRUB_TIMEOUT_STYLE=hidden → change to → GRUB_TIMEOUT_STYLE=menu

GRUB_TIMEOUT=0 → change to → GRUB_TIMEOUT=10

Then press Ctrl+S to save and Ctrl+X to exit nano. Then run the GRUB update command for your distro from Step 1.

Step 3 — Windows Still Missing? Disable Fast Startup in Windows

Windows Fast Startup locks the drive in a hibernation-like state and prevents GRUB from seeing Windows properly. Disable it.

  1. Boot into Windows (press F12 at startup and manually pick Windows)
  2. Open Control Panel → Power Options
  3. Click "Choose what the power buttons do"
  4. Click "Change settings that are currently unavailable"
  5. Uncheck "Turn on fast startup" and Save
  6. Reboot back into Linux and run sudo update-grub again

Step 4 — Fix From Windows If Linux Won't Boot

If you can boot Windows but Linux won't show up, open Windows Command Prompt as Administrator and run this to set GRUB as the default bootloader:

Run in Windows CMD as Administrator — sets GRUB as default boot manager
Windows CMD
bcdedit /set {bootmgr} path \EFI\ubuntu\grubx64.efi

After running the above in Windows CMD, restart — GRUB menu should now appear with both Linux and Windows.

Step 5 — Nuclear Option: Boot-Repair

Boot-Repair automatically diagnoses and fixes nearly every GRUB problem.

Install Boot-Repair
Debian/Ubuntu
sudo add-apt-repository ppa:yannubuntu/boot-repair -y && sudo apt update && sudo apt install boot-repair -y
Launch Boot-Repair
Debian/Ubuntu
boot-repair

In Boot-Repair, click "Recommended repair" and let it run. It will fix GRUB and restore the Windows entry automatically.

Also check in your BIOS/UEFI:

• Disable Secure Boot

• Set "ubuntu" or "Linux" as the first boot entry

• Disable Fast Boot in BIOS too if available

▶ Launch Boot-Repair
launch
boot-repair

Once it opens: Click "Recommended repair" — handles 95% of all boot problems automatically. It reinstalls/reconfigures GRUB, finds all your operating systems, and restores the boot menu. When done, reboot and remove your USB drive.

What Boot-Repair fixes: Broken GRUB · Windows missing from boot menu · Black screen on startup · System won't boot after update · Dual-boot issues · UEFI/SecureBoot problems · Corrupted MBR

Still broken? Boot-Repair generates a pastebin report URL. Copy it and post it on the Linux Mint Forums — experts can read the full diagnostic and help.

Can't get into any live session? Download the Boot-Repair-Disk ISO at sourceforge.net/projects/boot-repair-cd, flash to USB with Etcher, boot from it — Boot-Repair launches automatically.
