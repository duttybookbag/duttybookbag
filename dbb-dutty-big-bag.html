// What It Is

Dutty Big Bag

Multi-Symbol Market Dashboard

Dutty Big Bag is a multi-symbol analytics overlay that lets you monitor BTC, VIX, SPX, or NDQ from a single chart. It displays a live multi-timeframe table with momentum direction, compression state, trend direction, directional intensity, wave stages, combined dominance scoring, and a sentiment emoji system — all for the symbol you select.

For BTC, it also tracks BTC Dominance and USDT Dominance live. For VIX, the sentiment system adapts to fear/calm levels instead of standard bull/bear readings.

It does not tell you what to do. You monitor the data across markets and make your own decisions.

// What's Inside

Systems & Features

Multi-Symbol Selector
// BTCUSDT · VIX · SPX · NDQ

Switch between four major symbols without changing your chart. Select BTC, VIX, SPX, or NDQ from the settings and the entire table updates to show that symbol's data across all timeframes. Monitor multiple markets from one place.

Multi-Timeframe Analytics Table
// 7 timeframes · 1m to 1D

Live data table reading across 1m, 5m, 15m, 30m, 1h, 4h, and 1D simultaneously. Shows momentum direction (I/O column), compression state (S column), trend direction (SR column), and directional intensity (DI column) for each timeframe. Toggle any timeframe on or off.

Trend Direction — All 7 Timeframes
// Trend Direction on every timeframe

Unlike the standard Analytics Table which only shows SAR on higher timeframes, Dutty Big Bag calculates trend direction for all 7 timeframes — from 1-minute all the way to daily. See exactly where momentum sits on every level.

Combined Dominance System
// Volume + Momentum weighted across timeframes

A dual-engine dominance calculation that weighs volume power and momentum strength across all enabled timeframes. Higher timeframes carry more weight. Shows a single bull/bear dominance direction and percentage — tells you which side is winning overall.

Sentiment Emoji System
// Adaptive mood reading

A live emoji on your chart that reflects the overall market sentiment for the selected symbol. For stocks and BTC: 😊 Strong Bull, 🤨 Overbought Warning, 😟 Strong Bear, 🤔 Oversold Bounce, 😐 Squeeze, 😃 Normal. For VIX: 😱 Extreme Fear, 😟 Fear, 🤨 Caution, 😐 Neutral, 😊 Calm. Changes automatically as conditions shift.

BTC Dominance + USDT Dominance
// BTC only · live in the table

When monitoring BTC, the table shows a dedicated row with live BTC Dominance percentage and USDT Dominance percentage. Track the flow of capital between BTC and stablecoins without opening separate charts.

Wave Stage Detection
// B1–B3 Bull · R1–R3 Bear

Tracks directional wave progression with stages B1–B3 (bullish) and R1–R3 (bearish). Warning flashes yellow when the wave reaches an advanced stage. Market bias shown as BULL, BEAR, or NONE in the BIA row.

Compression Detection
// Squeeze states across all timeframes

Detects when price is squeezed or expanded on each timeframe. Displayed in the S column as lock (compressed) or bolt (expanded). Helps identify when multiple timeframes are coiling simultaneously.

Directional Intensity (DI)
// Dominant momentum per timeframe

Shows the dominant directional momentum on each timeframe. Once a direction is confirmed, it holds — giving you a clear read on whether buyers or sellers are in control. Filters out noise to show the bigger picture.

Live Price Display
// Always-on price row

A dedicated price row at the bottom of the table showing the current price of the selected symbol with the sentiment emoji. Always visible regardless of which timeframe toggles are on or off.
